# Как всё запустить — шпаргалка

## 1. Один раз: что установить

- **Python 3.11+** — `python3 --version`
- **Flutter** — нужен только для сборки админки: `flutter --version`
- **Git** с доступом к GitHub по SSH (уже настроено)
- **Caddy** — по желанию (`brew install caddy`): без него всё тоже работает

## 2. Запустить магазин (сервер на этом компьютере)

```bash
cd ~/Documents/saasplatform/saasshop
caffeinate -i ./scripts/server.sh
```

`caffeinate -i` не даёт Mac уснуть, пока магазин работает.

При **первом запуске** скрипт:
1. Сам поставит всё нужное для Python и соберёт админку (несколько минут).
2. Спросит **email, имя и пароль владельца** — с ними вы входите в админку.
3. Создаст файл настроек `backend/.server-data/server.env`.

Когда в терминале появится `✅ Магазин: https://….lhr.life` — магазин открыт для всех.

| Что | Где |
|---|---|
| Постоянная ссылка для покупателей | **https://habibullo155.github.io/foodtor/** — сама перекинет на текущий адрес |
| Магазин | адрес из терминала: `https://….lhr.life` (меняется при каждом запуске) |
| Админка с этого компьютера (быстро) | http://127.0.0.1:8000/admin/ |
| Админка из интернета | `https://….lhr.life/admin/` (первый раз грузится 1–2 минуты) |

**Остановить** — `Ctrl+C`. На постоянной ссылке появится «Магазин временно недоступен».

Если туннель не поднимается — включите VPN и запустите снова.

## 3. Настройки (файл `backend/.server-data/server.env`)

Откройте в любом редакторе, впишите и перезапустите сервер:

- `SMSRU_API_ID` — ключ с https://sms.ru. **Без него покупатели не смогут войти по номеру телефона.**
- `SHOP_PHONE`, `SHOP_EMAIL` — контакты на сайте.
- `SMTP_…` — почта для входа по коду из письма (необязательно).

## 4. Что настроить в админке

- **Товары** → «Импорт .xlsx / .csv» или «Новый товар». В товаре можно указать **оптовую цену**.
- **Магазин и доставка** → часы работы, Telegram и Instagram, зона доставки на карте.
- **Бизнес-клиенты** → минимальный заказ для оптовиков, подтверждение заявок компаний.
- **Истории** — «кружочки» на главной.
- **Сотрудники** — менеджеры, сборщики, курьеры.

## 5. После изменений в коде

```bash
git pull
caffeinate -i ./scripts/server.sh --build
```

`--build` пересобирает админку. Если менялся только сайт или сервер — можно без него.

## 6. Резервная копия

Все данные магазина (база, фото товаров, ключи) — в папке `backend/.server-data`.
Остановите сервер (`Ctrl+C`) и скопируйте эту папку на флешку или в облако. В git она не попадает.

## 7. Демо для показа (с тестовыми товарами)

```bash
./scripts/demo.sh
```

Откроется на http://localhost:8765 (админка — http://localhost:8765/admin/, логины — в `DEMO_ACCOUNTS.md`).
Демо и настоящий магазин не смешиваются: у них разные базы.
